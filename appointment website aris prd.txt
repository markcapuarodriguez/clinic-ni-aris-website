# Product Requirements Document (PRD)

## Simple Appointment Booking Website (Version 1.0)

---

# 1. Project Overview

## Project Name

**Clinic Appointment Booking System**

## Vision

Build a simple, clean, and intuitive appointment booking website specifically designed for **elderly Filipino patients with little to no computer experience**.

The system should enable patients to book appointments in under one minute while giving clinic staff an easy way to manage schedules and appointments.

The website should prioritize **simplicity over features**.

---

# 2. Objectives

The system should allow patients to:

* View available appointment dates.
* Book an appointment quickly.
* Receive an appointment confirmation with a downloadable QR code.
* Print the appointment if desired.

The system should allow administrators to:

* Manage clinic schedules.
* Manage appointment bookings.
* Update announcements.
* Check in patients using QR codes.

---

# 3. Target Users

## 7.6 QR Code

Every booking automatically generates a QR code.

The QR code should contain:

* Appointment ID
* Patient Name
* Appointment Date
* Appointment Time

Example payload:

```
Appointment ID: APPT000145
Name: Juan Dela Cruz
Date: July 20 2026
Time: 9:00 AM
```

QR code requirements:

* Free
* Downloadable
* Printable
* Unique

# 19. Acceptance Criteria

The application is considered complete when:

### Patient

* Can view available dates from a large, centered calendar.
* Can select only available future dates and times.
* Can complete a booking in four steps or fewer.
* Receives a confirmation page with a unique QR code.
* Can download or print the QR code.

### Administrator

* Can log in securely.
* Can manage schedules and appointments.
* Can update announcements.
* Can scan patient QR codes and mark appointments as checked in.

### General

* Entire interface is in Tagalog.
* Fully responsive on desktop, tablet, and mobile.
* Uses Local Storage for data persistence.
* QR code generation and verification require no paid services.
* Optimized for elderly users with large text, clear navigation, and minimal visual clutter.

---

## Success Metrics

* A first-time user can complete a booking in **under 60 seconds**.
* At least **90% of users** can finish a booking without assistance during usability testing.
* Staff can locate, verify, and check in a patient in **under 10 seconds** using the QR code.
* The interface remains simple enough that every core action (book, confirm, manage appointments) can be completed with **three or fewer primary clicks** after reaching the relevant screen.
